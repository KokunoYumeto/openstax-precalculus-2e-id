# OpenStax Precalculus 2e — Bahasa Indonesia

This repository contains an independent Bahasa Indonesia (`id-ID`) edition of
**OpenStax Precalculus 2e**, curriculum resource R002 / course A30. It does not
contain or represent the three earlier OpenStax foundation books or the other
works stored in the upstream bundle repository.

The modular backend contains 220,680 canonical records and 36 deterministic
exports. Two independent backend builds agree after the documented root-path

Translation and localization were produced with tool/process assistance on the
user's request. Model identification: OpenAI Codex gpt-5.6-sol, Ultra. This is a

The terminology policy was checked against Indonesian mathematical usage. Two
downloaded arXiv source packages were rejected as terminology witnesses because
their TeX bodies were English; the recorded fallback witnesses are an Indonesian

advanced-mathematics textbook. The evidence and decisions are preserved under
`evidence/terminology/m49361/` and `qa/TERMINOLOGY_QA_20260824.json`.

## Preservation

The complete `1.0.0` edition is preserved at
<https://doi.org/10.5281/zenodo.22290180>. The 3,165-page PDF is the primary
reader; compact source and modular-backend archives, license, manifest, README,
and checksums accompany it. All versions remain under Zenodo concept DOI
<https://doi.org/10.5281/zenodo.22059757>.

The corpus-specific public repository is
<https://github.com/KokunoYumeto/openstax-precalculus-2e-id>. Its `v1.0.0`
release mirrors the same seven files and preserves the earlier prerelease
history. Exact publication and anonymous byte-readback receipts are retained
under `qa/`.

## Structure

- `00_control/`: durable scope, cursor, authority, decisions, terminology,
  rights, backend version, and release receipts.
- `authority/`: immutable pinned repository evidence and source-closure hashes.
- `repo/`: editable Indonesian CNXML source and reader project.
- `backend/`: locale-neutral records and deterministic JSON/JSONL/CSV exports.
- `qa/`: structural, semantic, mathematical, language, rights, build, visual,
  and artifact evidence.
- `scripts/`: bounded deterministic tooling for this corpus only.
